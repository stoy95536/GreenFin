# GreenFin Product Specification

## 1. 一句話定位

GreenFin 是一套服務小農與金融機構的「綠色履歷資料治理與授信補充資訊平台」。

它將小農分散的生產、交易、循環利用、低碳耕作、驗證、學習與合作紀錄，經標準化、驗證與持續累積後，轉換成可追溯、可解釋的經驗值、四大分析指標與 Data Health，協助銀行更完整理解傳統財務資料以外的經營表現。

## 2. Product Boundary

GreenFin 不是：

- 自動核貸
- 信用評分
- 違約預測
- 額度／利率推薦

GreenFin 只提供授信補充資訊。

## 3. Core Users

### 小農
- 建立可攜式履歷
- 累積綠色行動
- 看見缺件與改善建議
- 控制資料授權

### 農漁會／銀行
- 取得結構化資料包
- 閱讀四大指標與 Data Health
- 追溯原始證據與規則版本
- 仍依自身制度完成授信

### 政府／地方單位
- 支持農業數位化、普惠金融、綠色轉型

### 資料／驗證夥伴
- 以核驗或 API 方式加入可信資料網絡

## 4. Three Output Layers

### 經驗值
呈現綠色行動近 12 個月的累積與參與，不是信用分數。

### 四大分析指標
- 資料完整度
- 資料可信度
- 經營成熟度
- 綠色成熟度

### Data Health
分項判斷資料是否目前可使用，並提供原因與下一步。

## 5. Data Scope

- 身分與資格
- 土地與作物
- 經營與交易
- 投入與設備
- 綠色行動
- 認證與治理
- 申貸用途

## 6. MVP / Demo

Demo 必須展示：

```text
上傳
→ 治理
→ 經驗值
→ 四大指標
→ Data Health
→ 銀行資料包
```

並涵蓋：
- 三種以上來源強度
- 過期案例
- 重複案例
- 異常案例
- 小農端
- 銀行端
- 原始證據追溯

## 7. Demo 最終邊界

Demo 要證明：

- 資料可以被治理
- 資料可以被累積
- 結果可以被分析
- 問題可以被提示
- 結果可以追溯

Demo 不需要證明經驗值可預測違約。
